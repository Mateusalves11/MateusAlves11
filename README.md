## 👨‍💻 Sobre mim

Sou **desenvolvedor Full Stack** e construo plataformas para o **mercado financeiro regulado** usando blockchain. Trabalho de ponta a ponta: interfaces em React e Next.js, APIs em Java e Kotlin com Spring Boot, autenticação, testes e pipeline de entrega.

- 🏦 Na **BBChain** desde 2023, em produtos de **tokenização de ativos**, **ativos digitais para instituições financeiras** e **créditos de carbono**
- 🧱 Gosto de código organizado: **Clean Architecture**, tipagem forte e componentes reutilizáveis
- 🔐 Experiência com regras de negócio sensíveis, perfis de acesso e integrações com **Keycloak**
- 👨‍🏫 Já dei aulas de programação (Futura Cursos e aulas particulares), então explicar o que faço é parte do trabalho
- 🌱 Estudando agora: **Kubernetes**, cloud e infraestrutura
- 🌎 Português nativo, inglês e espanhol intermediários
